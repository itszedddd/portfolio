# ⚡ Cedrick Jay Tobias — Developer Portfolio

Personal developer portfolio featuring a sleek cyber/hacker dark theme, matrix rain background, terminal hero section, interactive project showcase, and dynamic skill grids.

🔗 **Live Site:** [https://cedrick-portfolio.vercel.app](https://cedrick-portfolio.vercel.app) *(or your deployed Vercel URL)*

## 🚀 Built With
- **HTML5 & CSS3** — Vanilla CSS design tokens, glassmorphism, responsive grid & flexbox layouts
- **JavaScript (ES6+)** — Interactive Matrix rain canvas animation, custom cursor glow, real-time typing effect, scroll-triggered reveal animations, and counter effects
- **JetBrains Mono & Inter** — Clean developer-focused typography

## 📁 Project Structure
```
portfolio/
├── css/
│   └── style.css       # Design tokens, cyber aesthetics, responsive layout
├── js/
│   └── main.js         # Canvas animations, terminal typing, scroll observer
├── index.html          # Portfolio markup & SEO meta tags
├── vercel.json         # Deployment configuration & security headers
└── README.md
```

## 🛠️ Local Development
To preview locally, open `index.html` directly in your browser or run a simple static server:
```bash
npx serve .
```
